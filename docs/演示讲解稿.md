# 高校出国（境）交流项目智能管理系统 - 演示讲解稿

---

## 开场白（约1分钟）

尊敬的各位评委、专家，大家好！

我是本项目的演示人员，接下来由我为大家介绍和演示"高校出国（境）交流项目智能管理系统"。

本系统是面向高校国际交流处的一站式智能管理平台，覆盖学生出国交流的**全生命周期管理**，从项目发布、学生申请、派出审批，到在外管理、回国报到、学分兑换，实现了**全流程数字化、智能化**管理。

系统最大的特色是**深度融合AI技术**，在每个关键环节都有AI智能助手提供辅助，大幅提升管理效率和服务体验。

下面，我将按照业务流程，为大家进行详细演示。

---

## 一、系统概览与首页（约2分钟）

### 1.1 系统架构

首先，请看系统首页。我们的系统采用**三阶段管理模式**：

| 阶段 | 名称 | 核心功能 |
|-----|------|---------|
| 阶段1 | 派出前 | 项目申请、资格审核、材料准备 |
| 阶段2 | 派出中 | 在外情况跟踪、学习报告管理 |
| 阶段3 | 派出后 | 回国报到、学分兑换、电子归档 |

### 1.2 角色分工

系统支持**双角色视图**：
- **学生端**：完成各类申请和材料提交
- **管理端**：进行审核管理和数据统计

### 1.3 首页数据看板

首页集成了**智能数据看板**，管理员可以一目了然地看到：
- 待审核事项统计
- 在外学生分布地图
- 项目进度追踪
- AI预警提醒

## 二、项目管理模块（约3分钟）

### 2.1 项目发布查询

点击左侧菜单"项目管理" → "项目发布查询"。

这里展示了所有交流项目的列表，支持按**项目类型、状态、国家**等多维度筛选。每个项目卡片显示关键信息：合作院校、申请人数、截止时间等。

### 2.2 新建项目（重点演示）

点击右上角"+ 项目发布"按钮，进入项目创建页面。

**【亮点1：步骤式引导】**

项目创建采用**分步骤引导式设计**，分为两个步骤：
1. 第一步：项目基础信息
2. 第二步：预审规则配置（非必填）

在第一步，我们填写项目名称、合作院校、派出时间、报名截止时间，以及**材料提交截止时间**——这个时间将直接关联到后续学生的派出材料提交页面。

**【亮点2：AI预审规则配置】**

进入第二步，这是本系统的**核心创新功能**。

我们可以选择"快速规则模板"，系统预置了多套模板：
- 交换生项目标准模板
- 短期项目轻量模板
- 国际竞赛模板
- 空白模板（完全自定义）

选择模板后，下方自动加载预配置的规则条件。

**【演示规则配置】**

以"交换生项目标准模板"为例：
- 条件1：GPA成绩 ≥ 3.0
- AND：CET-6成绩 ≥ 425
- OR：雅思成绩 ≥ 6.0
- OR：托福成绩 ≥ 80

这些判断字段的数据来源于学生申请时填写的信息，实现了**申请数据与规则的自动匹配**。

我们还可以选择**规则类型**：
- **筛选规则**：硬性条件，满足即通过，不满足即不通过
- **评分规则**：软性条件，根据满足程度计算分数用于排序

规则预览区域会**实时生成**配置结果，方便管理员确认。

### 2.3 规则模板管理

点击"规则模板管理"，这里可以维护所有预审规则模板。

管理员可以**新建、编辑、复制、删除**模板，常用的规则组合可以保存为模板，在发布新项目时快速应用，提高工作效率。

## 三、阶段1：派出前流程（约5分钟）

### 3.1 学生申请（学生端）

现在切换到**学生视角**。

点击"派出前" → "项目申请"，学生可以看到所有开放申请的项目列表。

点击某个项目的"申请"按钮，进入申请页面。

**【亮点3：步骤式申请表单】**

申请表单分为4个步骤：
1. 基本信息
2. 学业信息
3. 语言成绩
4. 研修计划

右侧的**AI智能助手面板**始终可见，提供：
- 填写进度实时显示
- AI填写建议
- 智能问答（可以询问申请相关问题）

**【演示AI自动填充】**

点击"基础信息自动填充"按钮，系统从学生信息库自动同步姓名、学号、学院等信息，**无需手动输入**。

**【演示AI智能问答】**

在聊天框输入"这个项目对GPA有什么要求？"，AI助手会根据项目配置的预审规则，**自动回复详细的申请条件说明**。

### 3.2 申请审核（管理端）

切换到管理端，点击"申请审核"。

**【亮点4：AI预审筛选】**

系统已根据预审规则**自动完成初筛**：
- 绿色标签：预审通过
- 红色标签：预审不通过
- 橙色标签：建议人工复核

管理员可以点击"AI批量处理"按钮，一键通过所有预审通过的申请，**大幅减少重复性工作**。

点击某条申请的"详情"，可以查看学生完整的申请信息、材料附件，以及**AI评估报告**，辅助管理员做出审核决策。

### 3.3 派出材料提交（学生端）

申请通过后，学生进入"派出材料提交"页面。

页面顶部显示**材料截止时间**和**剩余天数倒计时**，提醒学生及时提交。

材料列表清晰展示每项材料的：
- 提交状态（已提交/待提交）
- AI验证结果
- 操作按钮

**【亮点5：AI材料验证】**

上传护照照片后，系统会**自动进行OCR识别**，验证：
- 护照是否在有效期内
- 姓名是否与申请信息一致
- 照片是否清晰可用

如有问题，AI助手会立即提醒学生重新上传。

### 3.4 派出材料审核（管理端）

管理端的"派出材料审核"页面，展示所有待审核的材料。

AI智能助手提供：
- 材料自动验证
- 签证有效期检查
- 文档OCR识别
- 紧急处理提醒（派出时间临近的优先审核）

## 四、阶段2：派出中管理（约3分钟）

### 4.1 在外情况填写（学生端）

学生派出后，需要定期填写"在外情况"。

这是一个**时间线式的记录界面**，学生可以记录：
- 当前住址和联系方式
- 学习进展
- 生活情况
- 遇到的问题

每次提交都会形成一条记录，方便管理员追踪学生动态。

### 4.2 在外情况查看（管理端）

管理端可以查看所有在外学生提交的情况报告。

支持按**国家、项目、时间**筛选，还可以查看**地图分布**，直观了解学生在全球的分布情况。

### 4.3 学习报告提交（学生端）

学生按要求提交阶段性学习报告。

**【亮点6：AI写作助手】**

右侧的AI助手提供：
- 报告大纲建议
- 内容优化提示
- 字数统计
- 截止日期提醒

### 4.4 学习报告查看（管理端）

管理端可以查看所有学习报告，支持**在线批阅**和**评语反馈**。

## 五、阶段3：派出后流程（约5分钟）

### 5.1 回国线上报到（学生端）

学生回国后，首先进行"线上报到"。

填写实际回国日期、航班信息，上传机票或行程单，完成报到登记。

### 5.2 恢复学籍办理（学生端）

交换生需要办理学籍恢复。

系统提供**办理指南**和**所需材料清单**，学生按要求提交后，等待审核。

### 5.3 成绩与学分兑换（学生端，重点演示）

**【亮点7：成绩与学分一体化流程】**

这是本系统的另一个**核心创新**。我们将原本分离的"成绩提交"和"学分兑换申请"合并为**一个连贯的4步流程**：

**第1步：上传成绩单**
- 支持PDF、图片格式
- AI自动进行**OCR识别**，提取课程信息

**第2步：确认课程信息**
- 系统展示识别结果
- 学生核对并补充修正
- 显示课程名称、学分、成绩、绩点

**第3步：学分兑换匹配**
- AI**自动推荐**对应的本校课程
- 学生可以调整匹配关系
- 系统计算兑换后的学分

**第4步：提交申请**
- 确认所有信息
- 上传补充材料（如有）
- 提交兑换申请

这种设计**减少了用户操作步骤**，数据在各步骤间**自动传递**，用户体验更流畅。

### 5.4 成绩与学分审核（管理端，重点演示）

**【亮点8：分步审核流程】**

审核页面顶部清晰显示**两步审核流程**：
1. 成绩审核 → 2. 学分审核

并提示：**成绩审核通过后，方可进行学分审核**。

列表中，操作栏会根据当前状态显示不同按钮：
- 待审核成绩 → 显示"审核成绩"
- 成绩已通过，待审核学分 → 显示"审核学分"
- 全部通过 → 显示"已完成"

点击详情，弹窗中有三个标签页：
- **成绩审核**：查看成绩明细，进行通过/退回操作
- **学分审核**：查看兑换映射，进行通过/退回操作（成绩未通过时禁用）
- **申请材料**：查看学生上传的原始材料

这种设计确保了**审核流程的规范性**，避免学分审核早于成绩审核的情况。

### 5.5 电子归档（学生端）

所有材料提交完成后，学生进入"电子归档"页面，查看自己的完整档案。

### 5.6 归档材料管理（管理端）

**【亮点9：项目类型差异化管理】**

不同类型的项目，归档材料要求不同：

| 项目类型 | 是否需要成绩单 | 是否需要学分兑换 |
|---------|--------------|----------------|
| 长期交换（≥3个月） | 需要 | 需要 |
| 短期交流（<3个月） | 不需要 | 不需要 |
| 暑期项目 | 不需要 | 不需要 |
| 联合培养 | 需要 | 需要 |
| 国际竞赛/会议 | 不需要 | 不需要 |

系统会根据项目类型**自动调整**材料要求清单，避免给学生造成困扰。

归档完成率、存储统计等数据在AI助手面板中实时显示。
